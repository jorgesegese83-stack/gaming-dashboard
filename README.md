# Gaming Achievements Dashboard

Dashboard de logros de Steam y PlayStation hecho con React, Vite y Tailwind CSS 3. Fase 1: datos simulados.

## Cómo correrlo

```bash
npm install
npm run dev
```

## Estructura

- `src/data/mockGames.js`: perfil, juegos y logros simulados, más funciones auxiliares.
- `src/components/ProfileHeader.jsx`: avatar, nivel, estado y barra de XP.
- `src/components/GameCard.jsx`: tarjeta de juego con progreso de logros.
- `src/components/AchievementModal.jsx`: detalle de logros con pestañas.
- `src/App.jsx`: filtros por plataforma y control del modal.
